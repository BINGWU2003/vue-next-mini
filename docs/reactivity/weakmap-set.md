# 1. 为什么使用 WeakMap 而不是 Map？

`targetMap` 是用来存储**原始对象（Target）**与**依赖映射（depsMap）**之间关系的全局容器。选择 `WeakMap` 的核心原因是：**自动垃圾回收（Garbage Collection）以防止内存泄漏。**

## A. 强引用 vs. 弱引用

- **Map (强引用):** 如果你使用 `Map`，即 `new Map([[target, deps]])`，那么 `Map` 会持有 `target` 对象的**强引用**。这意味着，只要这个 `Map` 存在（而在 Vue 中 `targetMap` 是全局存在的），`target` 对象就永远不会被垃圾回收（GC），即使你在代码中已经不再需要这个对象了。
- **后果：** 随着应用运行，创建的响应式对象越来越多，旧的对象无法释放，会导致严重的**内存泄漏**。

- **WeakMap (弱引用):** `WeakMap` 对其 key（即响应式对象）持有的是**弱引用**。
- **优势：** 如果用户代码中对该对象的其他引用都消失了（例如组件卸载，变量被置空），垃圾回收器（GC）会忽略 `WeakMap` 中的引用，直接回收该对象。一旦对象被回收，`WeakMap` 中对应的键值对也会自动消失。

## B. 场景举例

假设你有一个 Vue 组件，组件内部创建了一个巨大的响应式数据对象 `state`。

1. **当组件卸载时**，你希望 `state` 占用的内存被释放。
2. 如果 Vue 使用 **Map**：`targetMap` 依然抓着 `state` 不放，内存无法释放。
3. 如果 Vue 使用 **WeakMap**：一旦组件销毁，`state` 失去外部引用，GC 介入回收，`targetMap` 中关于 `state` 的依赖关系也随之自动清除。

> **总结：** 使用 `WeakMap` 是为了让响应式对象能够跟随组件或业务逻辑的生命周期正常销毁，无需手动清理依赖。

# 2. 为什么使用 Set 存储依赖集合？

`dep` 是存储某个具体属性（key）所有副作用函数（Effect）的容器。选择 `Set` 的核心原因是：**去重（Deduplication）**。

## A. 自动去重

在响应式系统中，一个副作用函数（Effect）可能会在一次执行中多次读取同一个属性。

**举个例子：**

```javascript
const state = reactive({ count: 1 });

effect(() => {
  // 这里的代码执行时，会触发两次 state.count 的 getter
  console.log(state.count + state.count);
});
```

- **如果使用 Array：**

1. 第一次读取 `state.count` -> 触发 track -> 将 effect `push` 进数组。
2. 第二次读取 `state.count` -> 触发 track -> 将 **同一个** effect 再次 `push` 进数组。
3. **结果：** 数组里有两个相同的 effect。当 `count` 改变时，这个 effect 会执行两次（这是错误的）。虽然可以通过 `Array.includes` 判断，但在频繁触发的大量依赖中，`O(n)` 的查找性能较差。

- **如果使用 Set：**

1. 第一次读取 -> `dep.add(activeEffect)`。
2. 第二次读取 -> `dep.add(activeEffect)`。
3. **结果：** `Set` 保证值的唯一性，重复添加无效。`dep` 中只有一个 effect。

## B. 性能优势

- **添加依赖：** `Set.add` 是 的操作（平均情况），且自带去重。
- **删除依赖：** 当 effect 重新运行时，往往需要清除旧依赖。`Set.delete` 也是 的，而 `Array` 需要先 `indexOf` 找到下标再 `splice`，性能开销大得多。

# 结构总结表

| 数据层级   | 数据结构  | Key (键)                    | Value (值)            | 选型理由                                                                           |
| ---------- | --------- | --------------------------- | --------------------- | ---------------------------------------------------------------------------------- |
| **第一层** | `WeakMap` | `Target` (响应式原对象)     | `depsMap`             | **内存管理**：对象销毁时自动回收依赖，防止内存泄漏。                               |
| **第二层** | `Map`     | `key` (属性名字符串/Symbol) | `dep` (Set)           | **键类型支持**：属性名通常是字符串，WeakMap 只能用对象做 Key，所以这里必须用 Map。 |
| **第三层** | `Set`     | (无，这是个集合)            | `Effect` (副作用函数) | **唯一性**：防止同一个副作用函数被重复收集，保证触发更新时只执行一次。             |
